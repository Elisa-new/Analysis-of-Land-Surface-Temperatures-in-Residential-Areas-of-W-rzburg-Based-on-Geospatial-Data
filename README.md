# Bachelorarbeit_LST_Wue

Dieses Repositorium beinhaltet die Codes zum Methodik Teil der Bachelorarbeit "Analyse der Landoberflächentemperatur in Würzburgs Wohngebieten anhand von Geodaten: Neu- und Bestandsgebiete im Vergleich". 

Das Notebook „GHSL“ bezieht sich auf die Identifikation der Untersuchungsbiete mittels des GHSL und beinhaltet die Beschreibung der Untersuchungsgebiete anhand der bebauten Fläche. Im Notebook „Beschreibung“ findet sich der Code zur Auswertung des DGM1, LoD2 und ALKIS Datensatzes, welche zur Charakterisierung der Untersuchungsgebiete dienten und das „Preproccesing“ Notebook beschäftigt sich mit der Vorverarbeitung der Landsat-Daten, es bereit diese für die Indikatorspezifischen Auswertung von „NDVI“, „LST“ und „Albedo“ vor. 
Für die manuelle Digitalisierung der Umrisse der Bebauungspläne wurde QGIS verwendet
